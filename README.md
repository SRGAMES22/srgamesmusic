# SRGames Music

Clone de aplicativo de música (estilo Spotify) com frontend moderno e backend.

## Estrutura
- `/front-end` → Frontend (Vite)
- `/back-end` → Backend Node.js

## Tecnologias
- Frontend: Vite + JavaScript
- Backend: Node.js

## Como executar
```bash
# Frontend
cd front-end
npm install
npm run dev

# Backend
cd back-end
npm install
npm start
